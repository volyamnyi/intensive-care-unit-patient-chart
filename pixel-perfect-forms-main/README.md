# Pixel Perfect Forms

Two reference images "form1.png" and "form2.png" are provided. Each image represents a form that must be recreated as an HTML/CSS interface.

Your task is to implement an exact, pixel-perfect reproduction of both forms based strictly on the provided reference images.

Requirements:

Treat every circle and square visible in the reference images as an input field or interactive form control.

Preserve the exact visual structure, including:

Positions and alignment

Dimensions and proportions

Borders, lines, and separators

Spacing, margins, and padding

Typography, font sizes, weights, and line heights

Labels and text placement

Checkboxes, radio buttons, and other controls

Form sections and their hierarchy

Reproduce the forms using clean, semantic HTML and CSS.

Do not redesign, simplify, modernize, or reinterpret the forms.

Do not replace form controls with generic placeholders or approximate components.

Every interactive field must be positioned exactly where its corresponding circle or square appears in the reference.

The final result should visually match the reference images at the pixel level, including on-screen dimensions and relative positioning.

Use responsive behavior only where necessary; do not allow responsiveness to alter the reference layout at the target viewport size.

If any visual detail is ambiguous, prioritize matching the provided image rather than applying your own design conventions.

The reference images are the single source of truth. Do not introduce any UI elements, styling, spacing, or behavior that is not supported by the references.
