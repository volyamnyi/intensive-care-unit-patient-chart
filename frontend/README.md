# ICU Patient Chart — Frontend

React 19 + TypeScript + Vite + MUI 9.

See the [root README](../README.md) for full project documentation, setup instructions, and run commands.

### Quick Start

```bash
npm install
npm run dev     # starts on http://localhost:5173
npm run build   # production build → dist/
npm run lint    # Oxlint static analysis
```
