## Виправлення race conditions в E2E тестах

Після завершення основного плану реалізації було виявлено та виправлено race condition між `doctor-chromium` тестами, які використовували `.first()` для вибору епізоду, що призводило до конфліктів при паралельному виконанні.

### Виконані зміни:
- **Перехід на явні ID епізодів** — всі тести тепер навігують на конкретний `episodeId` замість `.first()`
- **Розподіл епізодів**:
  - `a1111111`: `signoff-full-chain` (тест 1 підписує `b1111111`, тест 2 підписує `b1111112`), `signoff`
  - `a2222222`: `clinical-day-reopen` (використовує `b4444444` NURSE_SIGNED), `pdf-generation` (підписує `b2222222`)
  - `a3333333`: `notes`, `notes-full`, `prescriptions`, `prescription-cancel`
- **Додано `b4444444`** — новий NURSE_SIGNED клінічний день для `a2222222`, виділений для `clinical-day-reopen`
- **Дані ізольовані** — жоден тест не змінює дані, які використовуються іншим тестом
