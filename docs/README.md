React.js + Vite

## Java Spring Boot

Серверна частина системи, що реалізує всю бізнес-логіку процесу переливання крові. Відповідає за обробку заявок, контроль життєвого циклу процесу, взаємодію між користувачами, інтеграцію з МІС, управління правами доступу та виконання автоматичних бізнес-процесів.

---

## PostgreSQL

Централізована база даних, у якій зберігається вся інформація про заявки, користувачів, статуси, журнал подій, довідники та налаштування системи. Забезпечує цілісність, надійність та безпечне зберігання даних.

---

## Active Directory (LDAPS)

Використовується для централізованої автентифікації співробітників лікарні через корпоративний домен. Користувачі входять до системи під своїми службовими обліковими записами без створення окремих логінів і паролів.

---

## Spring Security (JWT)

Забезпечує безпечну роботу системи після входу користувача. Контролює доступ до функцій відповідно до ролі користувача (лікар, завідувач, медична сестра, адміністратор) та захищає взаємодію між клієнтом і сервером.

---

## REST API

Основний механізм обміну даними між вебінтерфейсом, серверною частиною та зовнішніми інформаційними системами. Використовується для виконання всіх стандартних операцій: створення, перегляду, редагування та отримання інформації.

---

## WebSocket (STOMP)

Забезпечує миттєве інформування користувачів про зміни в системі без необхідності оновлення сторінки. Наприклад, нові заявки, зміна статусу, призначення медичної сестри або автоматичні нагадування відображаються користувачам у режимі реального часу.

---

## Інтеграція з МІС

Система інтегрується з Медичною інформаційною системою лікарні для автоматичного отримання необхідних даних про пацієнтів, госпіталізації, лікарів та інші медичні відомості. Це мінімізує повторне введення інформації та забезпечує єдиний інформаційний простір. На даному етапі використовуємо мок дані.
