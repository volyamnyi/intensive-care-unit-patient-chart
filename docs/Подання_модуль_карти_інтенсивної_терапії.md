# Подання: Модуль електронної карти інтенсивної терапії (форма № 003-15/о)

Дата: 31.07.2026

Цей документ описує реалізований модуль «Карта інтенсивної терапії» (frontend `/icu/*`, backend Spring Boot `:8085`) у контексті переведення паперової форми первинної облікової документації № 003-15/о «Карта інтенсивної терапії» в електронну форму відповідно до вимог Інструкції, затвердженої наказом Міністерства охорони здоров’я України від 03 листопада 2025 року № 1675 (зареєстровано в Міністерстві юстиції України 23 грудня 2025 року за № 1926/45332; далі — Інструкція).

Документ містить:

- (а) процес трансформації паперової форми в електронну;
- (б) порівняльний аналіз з еталонною електронною версією форми (макет pixel-perfect);
- (в) алгоритм заповнення форми за пунктами Інструкції;
- (г) підтвердження відповідності вимогам Інструкції (чеклист);
- (д) рекомендації щодо подальшого вдосконалення UI/UX;
- Додаток А — витяг з Інструкції (повний текст).

## (а) Трансформація паперової форми в електронну

### а.1 Вихідний макет (еталон)

Еталонна електронна версія форми реалізована як піксельно точний HTML-макет паперового бланка (підпроєкт `pixel-perfect-studio-main`, Lovable). Ключові характеристики:

- **Сторінка 1** (`ChartPage1.tsx`): шапка з реквізитами закладу, сайдбар із даними пацієнта та шкалами, сітка показників на 24 години (колонки `8..24, 1..7`).
- **Сторінка 2** (`ChartPage2.tsx`): сітка догляду та лабораторних/інструментальних досліджень на 25 годин (колонки `8..7, 8`).
- **Геометрія сітки**: відступ `INDENT=150`, колонка назв `LABEL_W=270`, ширина години `HOUR_W=37` (стор. 1), висота рядка `ROW_H=19` (стор. 1) / `23` (стор. 2), сайдбар `SIDEBAR_W=300`.
- **Оформлення** (`styles.css`): гарнітура Times New Roman (`--font-form`), паперова текстура (`--color-form-paper`), чорнильний колір тексту (`--color-form-ink`), лінійки (`--color-form-rule`), класи `form-*` для рамок і вертикального тексту.

### а.2 Модель даних

Паперова форма перетворена на структуровану модель даних (сутності backend, `BaseEntity` з optimistic locking):

| Блок форми (папір) | Сутність / структура |
|---|---|
| Шапка (заклад, № карти, ПІБ, вік, діагноз) | `Episode` + дані пацієнта з МІС (`spzIBPatientSearch` — ПІБ, вік, група крові, резус, зріст, маса) |
| Доба перебування | `ClinicalDay` (номер доби, статус, підписи) |
| Показники по годинах | `HourlyRecord` (1 запис на годину, `UNIQUE(clinical_day_id, record_hour)`) |
| Призначена терапія | `MedicalOrder` + `OrderExecution` (виконання в годинах) |
| Фізіологічні втрати | поля `HourlyRecord`: `urineOutput`, `drainOutput`, `stool`, `vomit` |
| Вазопресори/інотропи | поля `HourlyRecord`: `dopamine`, `dobutamine`, `norepinephrine`, `epinephrine` (мкг/кг/хв) |
| Догляд, лабораторія, інструментальні дослідження | панелі `PatientStatePanel`, `LabResultsPanel`, `VentilationPanel` |
| Шкали (АРАСНЕ ІІ, SOFA) | `ScaleResult` (результат + `rawData` jsonb, прив’язка до епізоду) |
| Нотатки | `MedicalNote` (автор, роль, тип) |
| Баланс рідини | `FluidBalance` (intake/outcome/balance/cumulativeBalance, перерахунок з `HourlyRecord`) |
| Підписи | `Signature` (роль, `hash`, скасування при перевідкритті доби) |
| Зберігання/передача | `GeneratedPdf` (PDF доби, `TransferStatus`: PENDING/SENT/FAILED, надсилання до МІС через `sendPdf()`) |

### а.3 Бізнес-логіка

- **Медична доба**: години відображаються з 8:00 до 7:00 (`HOURS = (i+8)%24`); позиція години в добі `medDayPos(h) = h < 8 ? h+24 : h`; минулі години візуально виділені (`isPastMedDay`).
- **Автозбереження**: комірки сітки зберігаються автоматично через API (`hourlyRecordApi`).
- **Валідація**: клінічні діапазони (АТ 50–250/30–150, ЧСС 0–300, температура 34–42, SpO₂ 50–100 тощо) перевіряються JSR-380 та `@PrePersist/@PreUpdate`; конфлікти версій — HTTP 409.
- **Ролі**: лікар — призначення, шкали, нотатки; медсестра — показники моніторингу, втрати, виконання призначень (відповідає п. 3–4 Інструкції).
- **Блокування**: підписана/закрита доба не редагується (`isLocked`, `DocumentLockedException`); порядок підпису: медсестра → лікар.
- **Аудит**: кожна операція створення/зміни/видалення фіксується в `AuditLog`.

## (в) Алгоритм заповнення за пунктами Інструкції

Порядок заповнення електронної карти модулем, із посиланнями на пункти Інструкції (повний текст — Додаток А):

1. **Ідентифікація документа** (п. 1, 7): форма ведеться в електронному вигляді; блок «МЕДИЧНА ДОКУМЕНТАЦІЯ / Форма № 003-15/о / ЗАТВЕРДЖЕНО Наказ МОЗ» — рекомендація щодо відображення (див. (д)).
2. **Поступлення до ВАІТ/ВІТ/спецВІТ** (п. 2): відкриття епізоду та доби; окремий модуль «Листок лікарських призначень» (`/prescriptions/*`) відповідає формі № 003-4/о; автоматична відмітка припинення листка призначень — рекомендація (див. (д)).
3. **Ідентифікація пацієнта** (п. 3): ПІБ, вік, діагноз, група крові/резус, зріст, маса — підтягуються з МІС при створенні карти (`CreateCardPage`, пошук пацієнта `spzIBPatientSearch`).
4. **Показники моніторингу вітальних функцій** (п. 1, 4): медсестра заповнює по годинах: АТ сист/діас (мм рт.ст), ЧСС (в 1 хв), ЧД (в 1 хв), температура тіла (°С), SpO₂ (%), ЦВТ (мм вод.ст), EtCO₂, FiO₂ (%), GCS; середній артеріальний тиск розраховується автоматично `MAP = (2 × ДАТ + САТ) / 3`.
5. **Призначена терапія** (п. 3): лікар створює призначення (`MedicalOrder`); медсестра виконує з відміткою по годинах (`OrderExecution`) — відповідає п. 4 Інструкції.
6. **Вазопресорна та інотропна підтримка** (п. 3, «призначена терапія»): допамін, добутамін, норадреналін, адреналін (мкг/кг/хв) — по годинах.
7. **Фізіологічні втрати** (п. 3): сеча (мл/год), дренаж, випорожнення, блювота; сумарний діурез за 24 години враховується для SOFA.
8. **Догляд** (п. 3, «заходи по догляду»): положення у ліжку, головний кінець ліжка — рекомендація (див. (д)).
9. **Лабораторні/інструментальні дослідження** (п. 3): клінічний/біохімічний аналіз крові, коагулограма, аналіз сечі, УЗД, кисл.-лужний стан крові, Rg-графія, бактеріологічне дослідження — панель лабораторних результатів.
10. **Шкали** (п. 1): АРАСНЕ ІІ (12 фізіологічних показників за визначенням Інструкції; калькулятор — 20 параметрів стандартної методики), ступінь тяжкості ПОН за SOFA — розрахунок із збереженням `rawData`.
11. **Нотатки** (п. 3): лікар за необхідності; додаткова інформація від медичних сестер фіксується з позначенням автора та ролі.
12. **Баланс рідини** (п. 3): автоматичний перерахунок поступлення/виділення, добовий і кумулятивний баланс.
13. **Підпис** (п. 5): медсестра (сестра медична / брат медичний-анестезист) → лікар-анестезіолог; підпис фіксується з хешем і часом; доба стає недоступною для редагування.
14. **Зберігання та передача** (п. 6, 7): PDF доби формується із усіх даних форми, надсилається до репозиторію документів пацієнта в МІС (статус передачі відстежується); епізод архівується.

## (д) Рекомендації щодо вдосконалення UI/UX

Реалізовані зручності, які варто зберегти:

- підсвітка критичних значень (`CRITICAL_RANGES`: АТсист 90–180, АТдіас 60–120, ЧСС 50–130, температура 35.5–39.5, SpO₂ 90–100, ЧД 10–30, ЦВТ 2–14, GCS 8–15) з можливістю налаштування порогів;
- візуальне виділення минулих годин медичної доби (8:00–7:00);
- швидке введення з клавіатури (перехід Enter по комірках), автозбереження;
- рольові права інтерфейсу: медсестра бачить і редагує лише свій контур (показники, втрати, виконання), лікар — призначення, шкали, нотатки;
- зрозумілі статуси доби (Відкрита / Підписано медсестрою / Підписано лікарем) і блокування редагування після підпису.

Рекомендовані покращення:

1. **Втрати**: додати рядок «Зонд» (у еталоні — Сеча/Зонд/Випорожнення/Дренаж; у модулі «Зонд» замінено на «Блювота» — додати обидва рядки або перейменувати згідно з формою).
2. **Догляд**: додати розділ заходів догляду з фіксацією по годинах (положення у ліжку, головний кінець ліжка) — окрема сторінка/блок за аналогією зі стор. 2 еталону (25 колонок).
3. **Шапка документа**: відображати блок «МЕДИЧНА ДОКУМЕНТАЦІЯ / Форма № 003-15/о / ЗАТВЕРДЖЕНО Наказ МОЗ України від 03.11.2025 № 1675» та «Код за ЄДРПОУ» для однозначної ідентифікації електронного документа.

## Додаток А. Витяг з Інструкції щодо заповнення форми № 003-15/о

Джерело: https://zakon.rada.gov.ua/laws/show/z1926-25 — наказ МОЗ України від 03.11.2025 № 1675 (зареєстровано в Мін’юсті 23.12.2025 за № 1926/45332; опубліковано: Офіційний вісник України від 13.01.2026, № 4, ст. 358). Текст наведено згідно з офіційним вебпорталом (станом на 31.07.2026).

**1.** Ця Інструкція визначає порядок заповнення форми первинної облікової документації № 003-15/о «Карта інтенсивної терапії» (далі — форма № 003-15/о).

У формі № 003-15/о використовуються такі скорочення:

- діагноз — попередній або клінічний діагноз;
- номер карти стаціон. хворого — порядковий номер, який заповнюється при оформленні форми № 003/о «Медична карта стаціонарного хворого № ____», затвердженої наказом МОЗ України від 14 лютого 2012 року № 110 (у редакції наказу МОЗ України від 21 січня 2016 року № 29);
- АТ сист. (мм рт.ст) — систолічний артеріальний тиск;
- АТ діас. (мм рт.ст) — діастолічний артеріальний тиск;
- ЧСС (в 1 хв) — частота серцевих скорочень;
- SpO2 (%) — сатурація, показник рівня кисню в крові, вимірюваний за допомогою пульсоксиметра;
- темп. тіла (°С) — температура тіла пацієнта;
- ЦВТ (мм вод.ст) — центральний венозний тиск;
- ЧД (в 1 хв) — частота дихання;
- ВАІТ — відділення анестезіології та інтенсивної терапії;
- ВІТ — відділення інтенсивної терапії;
- спецВІТ — спеціалізовані відділення інтенсивної терапії різного профілю (трансплантаційного, кардіологічного або іншого профілю);
- потік O2 (л/хв) — кількість потоку зволоженого кисню;
- FiO2 (%) — фракція кисню у дихальній суміші;
- режим — режим неінвазивної або штучної вентиляції легень;
- ДО (мл) — дихальний об’єм;
- ХОД (мл) — хвилинний об’єм дихання;
- ПТКВ — позитивний тиск у кінці видоху;
- важкість стану за АРАСНЕ ІІ — шкала для оцінки тяжкості стану пацієнта, яка базується на 12 показниках життєдіяльності та фізіологічних параметрах;
- ступінь тяж. ПОН за SOFA — шкала оцінки органної недостатності в динаміці;
- ЕКГ — електрокардіограма;
- УЗД — ультразвукове дослідження;
- Rц-графія — рентгенографія.

**2.** Форма № 003-15/о заповнюється у ВАІТ, ВІТ або спецВІТ закладів охорони здоров’я, що надають спеціалізовану медичну допомогу в стаціонарних умовах.

При переведенні або поступленні пацієнтів на лікування до ВАІТ, ВІТ або спецВІТ ведення форми первинної облікової документації № 003-4/о «Листок лікарських призначень», затвердженої наказом МОЗ України від 29 травня 2013 року № 435 (далі — форма № 003-4/о), припиняється із відповідною відміткою «Пацієнт у ВАІТ (ВІТ, спецВІТ)» у графі «Дата» розділу «Відмітка про призначення та виконання» форми № 003-4/о.

При переведенні пацієнта із ВАІТ, ВІТ або спецВІТ для подальшого лікування в інше відділення відновлюється ведення форми № 003-4/о із відповідною відміткою «Пацієнт переведений із ВАІТ (ВІТ, спецВІТ)» у графі «Дата» розділу «Відмітка про призначення та виконання» форми № 003-4/о.

**3.** Форма № 003-15/о заповнюється лікарем-анестезіологом або лікарем-анестезіологом дитячим, або лікарем-педіатром-неонатологом ВАІТ, ВІТ або спецВІТ та містить інформацію про прізвище, власне ім’я та по батькові (за наявності) пацієнта, вік, діагноз, групу крові та резус крові, призначену терапію, фізіологічні втрати, заходи по догляду за пацієнтом, дані про призначені лабораторні та/або інструментальні дослідження для пацієнтів ВАІТ, ВІТ або спецВІТ.

Розділ «Нотатки» заповнюється лікарем-анестезіологом або лікарем-анестезіологом дитячим, або лікарем-педіатром-неонатологом ВАІТ, ВІТ або спецВІТ за необхідності вписування додаткової інформації від сестер медичних / братів медичних або сестер медичних / братів медичних-анестезистів ВАІТ, ВІТ або спецВІТ.

**4.** Дані про показники моніторингу вітальних функцій, виконання призначеного лікування у формі № 003-15/о заповнюються сестрами медичними / братами медичними або сестрами медичними / братами медичними-анестезистами ВАІТ, ВІТ або спецВІТ.

**5.** Форма № 003-15/о підписується лікарем-анестезіологом ВАІТ або ВІТ та сестрою медичною / братом медичним або сестрами медичними / братами медичними-анестезистами ВАІТ, ВІТ або спецВІТ.

**6.** Форма № 003-15/о після її заповнення вклеюється до форми первинної облікової документації № 003/о «Медична карта стаціонарного хворого № ____», затвердженої наказом МОЗ України від 14 лютого 2012 року № 110 (у редакції наказу МОЗ України від 21 січня 2016 року № 29), та зберігається протягом 25 років.

**7.** За технічної спроможності медичної інформаційної системи закладу охорони здоров’я форма № 003-15/о заповнюється в електронній формі, включає всі дані, які містяться у заповненій паперовій формі, та зберігається в медичній інформаційній системі закладу охорони здоров’я.
