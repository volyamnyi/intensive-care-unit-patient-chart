# Карта інтенсивної терапії — Посібник користувача

## Розгорнути карту на весь екран

Погодинну карту можна відкрити на весь екран для зручнішої роботи з великою кількістю даних.

**Як відкрити:**

- Натисніть кнопку **«Розгорнути на весь екран»** у шапці карти, або
- Двічі клацніть по заголовку **«Показник / година»**, або
- Натисніть клавіші **Alt + Enter**.

**Що всередині:**

- Повна погодинна сітка з усіма показниками, втратами рідини, вазопресорами та призначеннями.
- У шапці — ім'я пацієнта, номер доби, статус доби та лічильник критичних значень (натисніть, щоб перейти до першого).
- У футері — лічильник заповнення доби, кнопка **«Скасувати останню зміну»** та кнопка закриття.

**Клавіші:**

| Клавіша | Дія |
|---|---|
| `Tab` / `Shift+Tab` | Переміщення між елементами (фокус не виходить за межі вікна) |
| `Enter` | Зберегти значення в клітинці |
| `Esc` | Скасувати зміни в поточній клітинці (revert) або закрити вікно |
| `Alt+Enter` | Відкрити / закрити вікно |

**Важливо:**

- На підписаній добі всі клітинки недоступні для редагування — показується банер «Доба підписана — перегляд».
- Якщо дані змінив інший користувач, з'явиться жовтий банер із вибором: оновити дані або залишити свій варіант.
- При скасуванні виконання призначення з'являється тост із можливістю відновити (кнопка «Скасувати»).
- Останні 20 змін можна покроково скасувати кнопкою «Скасувати останню зміну».

## Листки лікарських призначень

### Керування днями призначень

Листок лікарських призначень містить сітку днів (за замовчанням показується 7 днів, прокрутка стрілками вліво/вправо). Кожне призначення має 4 часові смуги на день: **Ранок / День / Вечір / Ніч**.

Комірки підсвічуються за статусом: синє — «Заплановано», зелене — «Виконано», фіолетове — «Відмінено», біле — «Не заплановано». Дні, додані кнопкою «+» понад базовий 21-денний курс, позначені приглушеним фоном заголовка та неактивних комірок (легенда «Доданий день»); місце видаленого дня позначає смуга «Пропущений день» на заголовку наступного дня. Кольори статусів завжди мають пріоритет над цими позначками.

**Додати день** (тільки для лікаря та керівника відділу):

- У кожному рядку призначення доступна кнопка **«Додати день»** (+).
- Кнопка додає наступний день (після останнього наявного) з 4 не запланованими часовими смугами.
- Після додавання система автоматично оновлює перелік днів.

**Видалити день (кнопка «−»)** (тільки для лікаря та керівника відділу):

- У кожному рядку призначення поруч із «+» доступна кнопка **«−»** («Видалити день»).
- Кнопка видаляє ОСТАННІЙ день рядка (з максимальною датою) з його 4 часовими смугами — дія, протилежна до «Додати день».
- Можна видаляти порожні та заплановані дні.
- Якщо день містить виконане призначення (зелена комірка) — видалення неможливе, стан зберігається, з'являється повідомлення **«День містить виконані призначення, видалення неможливе»** (код `BUSINESS_RULE`, HTTP 422).
- Неможливо видалити останній день, що залишився в рядку.

**Відмінити це призначення** (тільки для лікаря та керівника відділу):

- Натисніть правою кнопкою миші по клітинці дози в сітці — відкривається контекстне меню.
- Виберіть **«Відмінити це призначення»**.
- Дія застосовується виключно до вибраної комірки конкретного періоду дня (Ранок / День / Вечір / Ніч) — сусідні комірки, інші періоди та рядки не змінюються.
- Комірка повертається у статус «Не заплановано» (білий фон без додаткової заливки).
- Пункт доступний, якщо комірка містить призначення (заплановане або відмінене); для виконаних (зелених) комірок дія недоступна — виконане призначення не може бути відмінене.
- Якщо в денному відрізку вже запланована доза — її також можна відмінити пунктом **«Відмінити препарат»**.

Для ролі медсестри ці дії недоступні — інтерфейс лише показує готовий стан листа.

**Відмінити препарат** (для відкритих клітинок, що вже заплановані):

- Правою кнопкою миші по клітинці дози — пункт **«Відмінити препарат»**.
- Доступний тільки тоді, коли клітинка запланована, але ще не виконана та не відмінена.
- Відмінена доза підсвічується фіолетовим (✕, статус «Відмінено»).

**Повернути у Заплановано** (для відмінених клітинок):

- Правою кнопкою миші по відміненій (фіолетовій) клітинці — пункт **«Повернути у Заплановано»**.
- Повертає дозу у статус «Заплановано» зі збереженням введеної дози.
- Недоступно для виконаних (зелених) клітинок.

### Ролі та дозволи

| Дія | ДОКТОР | Керівник відділу | МЕДСЕСТРА |
|---|---|---|---|
| Перегляд листа | ✅ | ✅ | ✅ |

## Виробництво протезів — Посібник користувача

### Початок роботи

1. Увійдіть в систему під rolлю **Технолог виготовлення протезів** (PROSTHETIST) або **Адміністратор протезування** (PROSTHETICS_ADMINISTRATOR).
2. На екрані вибору підсистеми натисніть **«Виробництво протезів»**.

### Дашборд

- Показує список ваших екземплярів процесу (instances).
- Фільтри: **Всі / Активні / Призупинені / Завершені / Провалені**.
- Кнопки дій: **Пауза / Продовжити / Переробити / Перегляд**.

### Мастер налаштування (Setup Wizard)

1. **Пошук пацієнта** — введіть ПІБ або частину імені, натисніть «Знайти».
2. **Вибір пацієнта** — натисніть «Обрати пацієнта» біля потрібного.
3. **Вибір замовлення** — оберіть замовлення зі списку, натисніть «Переглянути замовлення».
4. **Огляд замовлення** — перевірте дані (рецепт PDF завантажується автоматично). Кнопка **«Старт»** стає активною після завантаження PDF.
5. **Вибір шаблону** — оберіть відповідний шаблон (наприклад, TP-UL-01 для протезу передпліччя), натисніть «Обрати шаблон».
6. **Створення екземпляру** — система створює новий екземпляр процесу та відкриває **Мастер виконання (Wizard)**.

### Мастер виконання (Wizard)

- Послідовно пройдіть етапи: **Клінічне обстеження → Виготовлення → Контроль якості**.
- Кожен етап містить кроки з обов'язковими полями.
- Кнопка **«Готово»** неактивна, поки не заповнені всі обов'язкові поля кроку.
- Для кроків типу `FILE_UPLOAD` завантажте креслення/фото (PNG, JPG, PDF до 10 МБ).

### Контроль якості (Quality Gate)

- Після завершення технічних етапів екземпляр переходить на етап **Контроль якості**.
- Якщо ви **PROSTHETIST** — бачите статус «Очікує затвердження».
- Якщо ви **PROSTHETICS_ADMINISTRATOR** — бачите чек-лист та кнопки: **Пройдено / Не пройдено / Переробити**.

**Розуміння рішень:**
- **Пройдено (PASS)** — екземпляр переходить до завершення, доступний PDF-звіт.
- **Переробити (REWORK)** — екземпляр відкатується до вказаного кроку/етапу; технолог повторить роботу.
- **Не пройдено (FAIL)** — фіксується сніпшот провалу (причина, опис, вкладення); створюється заміна (новий екземпляр зі статусом NEW).

### Пауза / Продовження

- У будь-якому кроці натисніть **«Пауза»**.
- Оберіть причину: *Очікування матеріалів / Очікування схвалення / Технічна перерва / Інше*.
- Таймер кроку зупиняється, статус змінюється на `BLOCKED_MATERIALS`, `BLOCKED_APPROVAL`, `BLOCKED_TECHNICAL` або `BLOCKED_OTHER`.
- Для продовження натисніть **«Продовжити»** — таймер відновиться.

### Екран провалу (Failed Screen)

- При рішенні FAIL автоматично відкривається.
- Показує: причину, опис, вкладення, історію кроків.
- Кнопки: **Звіт про провал (PDF)** / **Створити заміну**.
- Нова заміна з'являється в дашборді зі статусом **NEW**.

### Екран успіху (Done Screen)

- Після PASS на етапі Контроль якості.
- Доступні: **Завантажити PDF-звіт**, **Повернутися на дашборд**.

### PDF-звіти

- **Рецепт** — на екрані огляду замовлення (iframe/embed).
- **Звіт екземпляру** — на Done Screen (повний звіт по етапах/кроках).
- **Звіт про провал** — на Failed Screen (деталі провалу для аналізу).

### Клавіші (Wizard)

| Клавіша | Дія |
|---|---|
| `Tab` / `Shift+Tab` | Навігація між полями кроку |
| `Enter` | Зберегти значення / перейти до наступного кроку (якщо валідно) |
| `Esc` | Скасувати зміни в поточному полі / закрити діалог |

### Ролі та дозволи

| Дія | PROSTHETIST | PROSTHETICS_ADMINISTRATOR |
|---|---|---|
| Перегляд дашборду (свої instances) | ✅ | ✅ |
| Створення екземпляру (Wizard) | ✅ | ✅ |
| Заповнення кроків / завантаження файлів | ✅ | ✅ |
| Пауза / Продовження | ✅ | ✅ |
| Рішення Quality Gate (PASS/REWORK/FAIL) | ❌ | ✅ |
| Створення шаблонів | ❌ | ✅ |
| Створення пацієнтів/замовлень | ❌ | ✅ |
