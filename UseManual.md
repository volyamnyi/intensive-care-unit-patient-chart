# Карта інтенсивної терапії — Посібник користувача

## Розгорнути карту на весь екран

Погодинну карту можна відкрити на весь екран для зручнішої роботи з великою кількістю даних.

**Як відкрити:**

- Натисніть кнопку **«Розгорнути на весь екран»** у шапці карти, або
- Двічі клацніть по заголовку **«Показник / година»**, або
- Натисніть клавіші **Alt + Enter**.

**Що всередині:**

- Повна погодинна сітка з усіма показниками, втратами рідини, вазопресорами та призначеннями.
- У шапці — ім'я пацієнта, номер доби, статус доби та лічильник критичних значень (натисніть, щоб перейти до першого).
- У футері — лічильник заповнення доби, кнопка **«Скасувати останню зміну»** та кнопка закриття.

**Клавіші:**

| Клавіша | Дія |
|---|---|
| `Tab` / `Shift+Tab` | Переміщення між елементами (фокус не виходить за межі вікна) |
| `Enter` | Зберегти значення в клітинці |
| `Esc` | Скасувати зміни в поточній клітинці (revert) або закрити вікно |
| `Alt+Enter` | Відкрити / закрити вікно |

**Важливо:**

- На підписаній добі всі клітинки недоступні для редагування — показується банер «Доба підписана — перегляд».
- Якщо дані змінив інший користувач, з'явиться жовтий банер із вибором: оновити дані або залишити свій варіант.
- При скасуванні виконання призначення з'являється тост із можливістю відновити (кнопка «Скасувати»).
- Останні 20 змін можна покроково скасувати кнопкою «Скасувати останню зміну».
